# 知伴图标规范

知伴使用一套按职责划分的图标体系。相同职责必须使用相同画布、图标家族、线重、容器和触控区域。不同职责不强行使用同一个数值。

## 尺寸

| 职责 | 图形尺寸 | 常见位置 |
| --- | ---: | --- |
| 内联状态 | 18 dp | 对勾、锁、右箭头、文字旁状态 |
| 输入字段 | 20 dp | 搜索、输入框内辅助图标 |
| 列表行首 | 22 dp | 设置项、能力项的柔和底色容器内 |
| 标准操作 | 24 dp | 返回、菜单、历史、附件、麦克风、发送 |
| 底部导航 | 24 dp | 日历、关系、问问、能力、我的 |
| 空状态插图 | 28 dp | 非交互的空状态提示 |

## 容器与触控

- 所有可点击图标的触控区域至少为 48 x 48 dp。
- 底部导航的选中底色为 40 x 40 dp，外层点击区域仍为 48 dp 或更大。
- 列表行首图标可放入 40-44 dp 柔和底色容器，但整行应作为主要点击区域。
- 52 dp 仅用于输入框中的主操作容器，不代表内部图标也要放大。

## 视觉一致性

- 通用功能图标统一使用 Material Symbols Outlined 风格；不在同一组操作中混用实心图标。
- “问问”与其他一级入口一样使用 Material Symbols Outlined 对话气泡，不使用单独放大的品牌图形。
- 选中状态通过主橙和柔和底色表达，不通过随意放大图标表达。
- 若同为 24 dp 仍显得大小不同，应调整图形在画布内的留白和视觉重心，不应在调用处为每个图标创建不同尺寸。
- 头像、品牌标志、联系人节点和录音波形不是操作图标，不套用本表。
