# 知伴移动端产品设计基线

这份基线约束整个 Android 客户端。目标不是复制某个页面的外观，而是让日历、关系、问问、能力、我的和所有设置页表现为同一个产品。

## 1. 产品气质

- 安静、直接、可信。内容优先，装饰退后。
- 只有一个品牌主橙 `#C97855`。主橙用于当前选择、关键操作和品牌识别，不创造“深橙”等第二品牌色。
- 面向普通用户写作。页面首先说明“能做什么、现在是什么状态、下一步怎么做”，内部技术名词只出现在确实需要配置的高级页面。
- 涉及发送、修改、删除、安装或授权时，把结果和影响说清楚，再让用户确认。

## 2. 字体

- 使用 Android 系统无衬线字体：拉丁字符由 Roboto 显示，中文使用设备匹配的 Noto Sans CJK。
- 所有字号使用 `sp`，遵循系统字体缩放。
- 页面主标题使用 `headlineSmall`；二级页面标题使用 `titleLarge`；卡片标题使用 `titleSmall` 或 `bodyLarge`；正文使用 `bodyLarge/bodyMedium`；说明和状态使用 `bodySmall/label`。
- 正文不使用粗体。中等字重用于标题和明确操作；粗体只用于极少数必须强调的短信息。
- 禁止页面自行声明字号。新增文字必须从 `MaterialTheme.typography` 选择语义角色。

## 3. 布局

- 主页面水平边距 20 dp，内容分组间距 24–32 dp，组内间距 8–12 dp。
- 日历、关系、能力、我的统一使用 64 dp 一级页顶栏：`headlineSmall` 标题、`bodySmall` 副标题和 48 dp 右侧操作区；标题基线不得由页面自行偏移。
- 顶栏基准高度 64 dp；返回按钮和右侧操作使用 48 dp 触控区域、24 dp 图标。
- 带副标题的列表行至少 72 dp，单行操作至少 64 dp。
- 普通卡片圆角 16 dp，输入框 18 dp，对话框 24 dp；胶囊圆角只用于标签、分段选择和底栏。
- 同一页面的标题与内容左边线必须一致；图标、文字、开关和箭头按视觉中心对齐。
- 页面使用系统状态栏、导航栏和键盘安全区。安全区只在应用壳层处理一次，页面不得重复增加。

## 4. 颜色和层级

- 页面、卡片、次级表面、文字、边框和错误状态统一使用 Material 颜色角色；页面代码不新增无语义的十六进制颜色。
- 浅色背景为 `#F7F7F8`，卡片为白色；深色模式使用主题对应的 surface 角色，禁止继续显示白卡和深灰硬编码文字。
- 页面主要靠背景与表面色区分层级。普通卡片不叠加边框和阴影；悬浮输入框、底栏等确有层级需求的组件才使用柔和阴影。
- 成功、警告、失败和危险操作各有统一语义色；状态不能只依赖颜色，还要有文字。

## 5. 组件

- 通用图标遵循 [图标规范](icon-system.md)。
- 输入、按钮、卡片、设置行、分段选择、状态标签和弹窗优先使用共享组件或 Material 3 组件。
- 普通内容卡统一使用 `zhiBanCardSurface`：16 dp 圆角、`surface` 背景、无边框和阴影；提示卡只把背景换成 `surfaceVariant`，不得另造圆角。
- 连续列表使用一个 16 dp 外层卡片配内部分隔线，不把每一行画成不同规格的独立卡片。输入框和弹窗不是普通卡片，分别使用 18 dp 和 24 dp 语义圆角。
- 所有可点击区域至少 48 x 48 dp，相邻触控区域保留足够间隔。
- 页面只保留一个明确的主要操作。次要操作使用文字按钮或菜单，不与主要操作竞争。
- 临时结果使用 Snackbar；必须立即决策的场景才使用对话框；需要连续浏览或编辑的内容进入独立页面或底部抽屉。

## 6. 导航与用户习惯

- 底栏只用于五个一级目的地：日历、关系、问问、能力、我的。文字可隐藏，但必须保留 TalkBack 标签。
- 问问进入全屏对话，不显示底栏；系统返回键和页面返回键都回到进入前的一级页面，不得失效。
- 二级页面统一使用左上返回，并同时支持 Android 系统返回与预测返回。
- 切换一级页面时保留该页面的滚动位置和筛选状态；新建对话是显式动作，不因切换页面自动丢失会话。
- 键盘弹起时隐藏底栏，输入框始终位于键盘上方；返回键第一次关闭键盘或弹层，第二次离开页面。

## 7. 状态和文案

- 每个异步页面都应覆盖：加载、空、成功、失败、无权限、离线和重试状态。
- 错误文案包含“发生了什么”和“用户可以怎么恢复”，不向普通用户展示异常代码或原始 JSON。
- 危险操作使用具体动词，如“删除这段对话”“清除 API Key”，不用含糊的“确定”。
- 权限说明先解释用途，系统授权框只在用户触发相关功能时出现。
- 技术名词需要翻译：MCP 对用户显示为“外部服务”，模型推理档位显示为“快速/标准/深入”。
- 页面副标题只回答“这里能做什么”；卡片副标题只回答“这一项能做什么”，默认保持一行，细节放进详情页。
- 删除重复承诺、实现原理和防御性解释；按钮使用动作词，状态使用“可用、未连接、需确认”等短语。

## 8. 无障碍与验收

- 图标按钮提供准确的 `contentDescription`；纯装饰图标设为 `null`，避免重复朗读。
- 选中、连接、录音、转写和执行状态需要可被 TalkBack 感知。
- 至少验证系统字体 100% 和 130%，浅色和深色模式，键盘打开/关闭，权限允许/拒绝，以及无网络状态。
- 发布前在真实 Android 路由逐屏检查：日历、关系、问问、能力、我的、智能体设置、大模型连接、记忆、工具和所有系统设置页。
