# 百度实时 ASR 受控测试结论

日期：2026-07-19  
范围：仅 Debug/受控测试；不构成公众 Release 上线批准。

## 实测结果

- 产品路径：百度实时语音 WebSocket，非短语音 Android AAR。
- 协议：`START` 文本帧 → 16 kHz/16-bit/mono PCM Binary 帧 → `FINISH` 或 `CANCEL`。
- 帧门：20–200 ms；主测试使用 160 ms（5120 B）。
- 公开中文样本：原始 138372 B；末帧补齐后发送约 138880 B，即约 4.34 秒音频。
- 真实返回：`MID_TEXT` 与 `FIN_TEXT` 均收到；首结果小于 10 秒；内部 CER 门不高于 40%；加强标点门通过。测试不输出识别正文。
- 取消：撤回同意后立即发送取消并封口，后续音频和迟到回调均被拒绝。
- 硬断线：在尚无已提交 `FIN_TEXT.end_time` 时断开，重新连接并从水位 0 重放，恢复到 `MID_TEXT/FIN_TEXT`。
- 受限网络：Android Emulator 设置 EDGE 速率（上下行 473600 bit/s）和 GPRS 延迟（35–200 ms）后，真实 MID/FIN、取消、断线重放三项测试均通过；测试后已恢复无限速/零延迟。
- 全量门：75 项 instrumentation 与 Debug unit 全绿；Release R8 反向扫描无测试凭据、无短语音 AAR/native。

## 耗量与成本口径

- 本轮可验证的真实客户端耗量是音频字节与时长：约 138880 B / 4.34 秒/完整识别；断线且无已提交水位时会从零重放，因此网络发送量和供应商处理时长可能增加。
- 百度控制台最终计费记录本轮未读取，标记 **NOT VERIFIED**；不得把客户端字节数直接冒充账单金额。
- 正式成本必须由服务端按用户、会话、请求 `sn`、发送音频毫秒、重放毫秒和供应商账单对账。

## 并发、限流与熔断结论

- 当前 Debug 客户端直连只能做单会话 fail-closed；没有跨用户并发配额、总量限额或集中熔断能力。
- 官方资料中的账号并发额度属于共享供应商应用，不是“每个知伴用户独享”。客户端直连也会暴露共享 AppKey，不能进入公众 APK。
- 生产必须经知伴 ASR Gateway：短期令牌/服务端凭据、单用户与全局并发、时长预算、排队/拒绝、错误率与延迟熔断、取消传播、审计和供应商账单对账。默认不保存原始音频。
- 建议熔断输入：认证/配额错误立即 fail-closed；连续连接失败、错误率或 p95 延迟越阈值时暂停新会话；半开只放少量探测；客户端显示可恢复错误，不无限重试。

## 上线硬门

1. Release 继续默认关闭且零凭据。
2. 隐私明示同意前不连接、不采集；撤回后立即取消。
3. 建立服务端 Gateway 和可审计配额/熔断后，重新进行 Owner 安全与成本决策。
4. 补供应商账单对账、正式 SLA/地域/留存条款核验。
