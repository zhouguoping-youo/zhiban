## 执行模式

- A0 至 H：`qualityReport` 随根 `check` 执行，Detekt、Ktlint 和项目审计生成报告但不因存量问题阻断。
- A1：默认切换严格模式，不使用 baseline 文件；超过 1,000 行、精确重复块、取消语义风险及 Detekt/Ktlint 违例均阻断 `check`。
- 文件体积统一按 `gradle/quality.gradle.kts` 的“有效行”算法计量：600–1,000 有效行保留为警告，超过 1,000 有效行为错误。`scripts/measure.sh` 必须复用同一算法；物理行只作为阅读成本参考，不能再与阻断口径混用。
- 静态规则只给出候选。任何业务改动仍须读最终调用点、补回归测试并通过完整构建和真机闸。

## 报告位置

- 根项目审计：`build/reports/quality/`
- Detekt：各模块 `build/reports/detekt/`
- Ktlint：各模块 `build/reports/ktlint/ktlintMainSourceSetCheck/`

工具版本：Detekt 1.23.8、Ktlint Gradle Plugin 14.2.0、Ktlint 1.8.0。
